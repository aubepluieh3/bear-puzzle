# 여기에 퍼즐 그림을 넣으세요

`bear.png` 라는 이름으로 저장하면 게임이 자동으로 찾아 씁니다.

인식하는 이름 (위에서부터 먼저 찾습니다):

1. `bear.png`
2. `bear.jpg`
3. `bear.jpeg`
4. `bear.webp`

## 팁

- **정사각형**에 가까울수록 예쁩니다. 아니어도 가운데를 잘라 쓰니 늘어나진 않아요.
- 600×600 ~ 1200×1200 px 정도가 적당합니다.
- 파일을 옮기기 귀찮으면 게임 화면의 **🖼️ 이미지 바꾸기** 버튼을 쓰세요. 다만 새로고침하면 초기화됩니다.
- 얼굴이나 무늬가 뚜렷한 그림이 퍼즐로 훨씬 재미있습니다. 단색 배경이 넓으면 어디에 놓을지 알 수 없어서 어렵기만 해요.
